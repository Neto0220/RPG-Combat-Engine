# Segurança

## Dados privados

Este repositório é público. Não publique fichas reais, saves, tokens, chaves, credenciais, dados pessoais ou arquivos exportados de campanhas privadas em Issues ou Pull Requests.

## Vulnerabilidades

Se encontrar um problema que exponha dados, permita execução inesperada de código ou afete integrações que usem este motor, evite publicar detalhes exploráveis em uma Issue pública. Entre em contato com o mantenedor por um canal privado disponível no perfil do GitHub.

## Escopo

O núcleo do RPG Combat Engine não realiza rede, autenticação ou persistência por conta própria. Aplicações que integrem o motor continuam responsáveis por segurança de armazenamento, permissões e transporte de dados.
