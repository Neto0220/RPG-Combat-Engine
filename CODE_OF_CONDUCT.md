# Código de Conduta

Este projeto busca uma comunidade técnica, colaborativa e respeitosa.

Contribuições devem discutir código, regras e comportamento do motor de forma objetiva. Assédio, ataques pessoais, discriminação, publicação de dados pessoais ou comportamento deliberadamente hostil não são aceitos.

Mantenedores podem editar, ocultar ou remover conteúdo que viole estas regras e restringir participação quando necessário.

Ao relatar um problema de conduta, evite expor informações pessoais publicamente; utilize os canais privados disponíveis no perfil do mantenedor.
