# Roadmap

## Curto prazo

- schema JSON formal para personagens e mecânicas;
- validação de entrada com mensagens amigáveis;
- API de condições declarativas;
- prioridades/ordem explícita de modificadores;
- crítico, acerto, esquiva e defesa configuráveis;
- regras de cooldown;
- efeitos com duração em turnos;
- serialização/versionamento de estado.

## Médio prazo

- sistema de plugins de regras;
- pacote publicado em registry;
- TypeScript declarations;
- simulador estatístico;
- adaptadores para React/Vue e aplicativos móveis;
- documentação interativa.

## Ideias da comunidade

Use Issues com o template **Nova mecânica** para propor regras. Propostas devem trazer exemplos de entrada, resultado esperado e casos-limite.
